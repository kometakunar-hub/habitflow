# HabitFlow — мой личный трекер привычек

Киберпанк-PWA для построения дисциплины и укрепления привычек.

## Описание

HabitFlow — это персональный трекер привычек в стиле киберпанк. Приложение адаптировано под компьютер, планшет и смартфон, поддерживает светлую и тёмную темы, работает офлайн благодаря Service Worker и может устанавливаться на домашний экран как PWA.

## Возможности

- Главная страница с презентацией продукта
- Дашборд «Today» с прогрессом, чекбоксами и динамикой
- Список всех привычек с фильтрами, стриками и пропусками
- Создание и редактирование привычек
- Категории привычек с иконками
- Календарь / история с тепловой картой
- Статистика привычки и общая статистика
- Личный кабинет с переключением тем
- 404-страница
- Нижняя навигация для мобильных устройств и боковое меню для десктопа

## Технологии

- HTML5
- CSS3 (CSS-переменные, Grid, Flexbox, адаптивный дизайн)
- Vanilla JavaScript (ES6+)
- LocalStorage для хранения данных
- Service Worker для офлайн-работы
- Web App Manifest для установки на домашний экран

## Запуск

Просто откройте `index.html` в браузере или разверните файлы на любом статическом хостинге.

```bash
# Пример локального сервера
npx serve .
```

## Структура

- `index.html` — точка входа
- `styles.css` — стили и темы
- `app.js` — логика приложения
- `manifest.json` — манифест PWA
- `sw.js` — Service Worker
